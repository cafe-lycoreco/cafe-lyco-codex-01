# cafe-lyco-codex-01

チャットや作業環境をまたいで、プロジェクトのファイルと引き継ぎ記録を使うためのリポジトリです。

## 保存場所

| 場所 | 保存するもの |
| --- | --- |
| `projects/<プロジェクト名>/` | プロジェクトのコード、資料、残したい生成物 |
| `shared/INDEX.md` | プロジェクトと引き継ぎ記録へのリンク |
| `shared/decisions.md` | 今後も使う決定事項とその理由 |
| `shared/sessions/` | 各作業の結果、未完了事項、次にすること |
| `shared/templates/session.md` | 引き継ぎ記録のひな形 |
| `AGENTS.md` | このリポジトリを使うエージェントへの読み書きルール |

## 次のチャットで使う

このリポジトリを含む環境を選び、次のように伝えてください。

> cafe-lyco-codex-01 の AGENTS.md と shared/INDEX.md を読み、関連する引き継ぎ記録を確認してから作業を続けてください。

ローカルでは、このリポジトリをプロジェクトの主フォルダにすると、Codexが`AGENTS.md`を見つけやすくなります。別の環境では、同じリポジトリの最新の変更を取得してから始めます。

## 作業を残す

意味のある作業の区切りで、`shared/templates/session.md`をコピーして`shared/sessions/<日付>-<作業名>.md`を作り、`shared/INDEX.md`にリンクを追加します。継続して使う決定だけを`shared/decisions.md`に残します。

エージェントには、次のように依頼できます。

> 作業の要点と次にすることを共有記録に残し、今回の変更をGitHubへ保存してください。公開範囲を確認し、対象ファイルだけをcommit・pushしてください。

ファイルを変更しただけではGitHubには保存されません。commitは変更の記録、pushはその記録をGitHubへ送る操作です。別のチャットから読めるのは、GitHubへ反映された変更です。ブランチが異なる場合は、共有するブランチへの取り込みも必要です。

## 公開範囲とチャット履歴

このひな形には会話本文や個人情報を含めていません。公開リポジトリの内容は誰でも読めます。会話の要点、個人的な設定、非公開資料を残す場合は、先に非公開リポジトリを保存先にしてください。

これは共有ファイルを使う仕組みです。ChatGPTやCodexの全チャット履歴を自動取得・同期する機能ではありません。過去の会話を引き継ぐには、そのチャットで作った要約や、ユーザーが提供した記録を保存します。

依存パッケージや再生成できるキャッシュは作業環境で扱います。次の環境でも再現するには、依存関係の定義、バージョン固定ファイル、必要な実行手順をプロジェクトに残します。生成物を残す場合は、そのプロジェクトの`outputs/`などへ保存して明示的にGitへ追加してください。

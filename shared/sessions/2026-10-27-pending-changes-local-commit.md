# 保留中のソース・運用資料をローカルGitへ保存

- 日付: 2026-10-27
- プロジェクト: [Computer-use MCP](../../projects/computer-use-mcp/README.md) とリポジトリ共通資料
- 状態: 内容確認・静的検証済み。この記録を含むコミットでローカル保存。pushは未実施。

## 目的

保留されていたソース、配布ZIP、運用ルールと公開可能な引き継ぎ記録を、現在のブランチでまとめて保存する。

## 実施したこと

- [Computer-use MCPのソースと配布物](../../projects/computer-use-mcp/README.md)、[作成時の記録](2026-10-10-computer-use-mcp.md)を保存対象にした。
- [エージェント向けルール](../../AGENTS.md)の検索演算子・モデル提案方針と、共有索引・継続する決定の更新を保存対象にした。
- [README](../../README.md)のプロジェクト名を統一し、旧チェックアウト名を現在の固定フォルダ名とする説明を訂正した。
- 個人設定、会話、調査資料を含む `.local/` とルート `.codex/` のGit除外を維持した。認証情報は記録しない。

## 検証

- `git diff --check`、シェル構文、Python構文、JSONとSVGの解析を確認。
- 配布ZIPのCRC、重複パスなし、ソース全9ファイルとの全バイト一致、同梱SHA-256との一致を確認。
- 保存対象のテキストとZIP内ソースを確認し、資格情報形式や個人の絶対パスが含まれないことを点検。
- 今回は個別アプリの操作検証や、導入済みホストの権限変更を行っていない。作成時のMCP接続検証の範囲は旧記録を参照する。

## 決定と理由

ユーザーの依頼に従い、未コミットの公開可能な変更を現在のブランチに保存する。ブランチ切替え、履歴書換え、GitHubへの送信は行わない。

## 未完了事項と次の手順

GitHubへの反映が必要になった場合は、リモートと共有先ブランチの現在の状態を確認してから別途pushする。

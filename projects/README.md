# プロジェクト

プロジェクトごとにフォルダを作り、コード、資料、残したい生成物をまとめます。

```text
projects/
  example/
    README.md
    src/
    outputs/
```

各プロジェクトの`README.md`には、目的、現在の状態、実行手順、必要な依存関係を記載してください。実際の内容に合わせてフォルダを作り、`../shared/INDEX.md`にも登録します。

生成物は、ファイルを置くだけでなくGitへ追加してpushすることで、別の環境から利用できます。大きなバイナリや頻繁に変わる大量のファイルには、Git LFSや別のファイル保管サービスを検討してください。
